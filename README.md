# Simple Interest Calculator

This project calculates simple interest using the principal amount, annual interest rate, and time in years.

## Inputs

- **P** — principal amount.
- **R** — annual interest rate, expressed as a percentage.
- **T** — time period in years.

## Formula

Simple interest = (P × R × T) / 100

## Example

For a principal amount of 1000, an annual interest rate of 5%, and a period of 2 years, the simple interest is 100.
